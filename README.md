# Math Site

A lightweight math-focused website for teaching and learning.

## Overview

This project is a simple educational site centered around mathematics. It can be used as a base for classroom resources, practice problems, lesson content, or interactive math tools.

## Project Structure

- `index.html` — main landing page
- `styles.css` — site styling
- `script.js` — interactive behavior
- Additional assets and pages can be added as the project grows

## Getting Started

1. Clone the repository.
2. Open the project in your browser or serve it locally using a simple web server.
3. Customize the content, exercises, and design to fit your teaching goals.

## Example local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Notes

This repository is intentionally simple and easy to extend for classroom use, lesson pages, and math exercises.
